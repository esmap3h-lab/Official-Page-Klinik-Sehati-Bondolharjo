# Official Page Klinik Sehati Bondolharjo

Website resmi Klinik Sehati Bondolharjo yang menyediakan layanan pendampingan legalitas usaha bagi pelaku UMKM, termasuk pembuatan Nomor Induk Berusaha (NIB), sertifikasi halal, serta layanan konsultasi dan pendampingan usaha.

## Tentang Proyek

Website ini dikembangkan sebagai platform informasi dan layanan digital untuk membantu pelaku UMKM dalam memenuhi persyaratan legalitas usaha dan sertifikasi halal. Selain itu, website ini juga menjadi media informasi dan pendaftaran bagi masyarakat yang ingin berpartisipasi dalam program pendampingan produk halal.

## Fitur Utama

- Informasi layanan pembuatan NIB
- Informasi dan pendampingan sertifikasi halal
- Informasi persyaratan legalitas usaha
- Formulir pendaftaran layanan
- Informasi program pendampingan UMKM
- Kontak dan lokasi Klinik Sehati Bondolharjo
- Tampilan responsif untuk desktop dan mobile

## Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Tujuan Website

- Membantu UMKM memperoleh NIB
- Mendukung proses sertifikasi halal produk
- Menyediakan akses informasi legalitas usaha
- Meningkatkan kesadaran pelaku usaha terhadap pentingnya sertifikasi halal
- Mempermudah akses layanan pendampingan usaha
